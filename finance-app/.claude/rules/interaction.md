# Interaction Style Rules (interactive sessions only — ignore in automated agent mode)
- Plan before generating: show all classes/components you intend to create and get confirmation before writing any code
- Generate one class at a time: pause for feedback after each class before moving to the next
- Tests before implementation: write unit tests first, present for review, then write the production class
- Architecture questions: analyse the code and provide a high-level overview before proposing any changes
